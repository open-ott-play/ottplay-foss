# OTTPlay webOS source relocation

The native OTTPlay application is maintained in
[open-ott-play/ottplay-lg](https://github.com/open-ott-play/ottplay-lg).
Use that repository for its source, build, installation and release guides.

## Historical corresponding source

The complete imported FOSS native source is retained at immutable commit
[`47adabad66b41b33e126925f7f00b17c7bf19b58`](https://github.com/open-ott-play/ottplay-foss/tree/47adabad66b41b33e126925f7f00b17c7bf19b58/native/webos).
The [FOSS 1.1.70 source](https://github.com/open-ott-play/ottplay-foss/tree/a8c386eef0654c3ddbf9ea429b636bd148f4f0e5/native/webos)
also retains its complete producer, patches and
[original license notice](https://github.com/open-ott-play/ottplay-foss/blob/a8c386eef0654c3ddbf9ea429b636bd148f4f0e5/native/webos/COPYING).
Existing tags, source archives and published assets retain their original content.

This documentation-only directory keeps existing application source/legal links
resolvable after the duplicate FOSS native producer is retired. The maintained
LG repository records its source import and license provenance. See the
[FOSS migration and compatibility notes](../../docs/native-webos.md).
