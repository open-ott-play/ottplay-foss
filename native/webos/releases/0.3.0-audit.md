A later scoped Mac run used source `0751131eee8c0a2a358d3bab6fc669a11765e749`
and executable SHA-256 `1a898121d0c5ee22f927c9043dacde2182b7e060419158847b7e85ac1a710fec`.

catalogue/player round trips and transitions between two distinct Local files.

## Source scope reviewed

The user-guide revision was checked against native integration source `bfa8b52be91b4b3651ae1fe644630a71de8fde23`. This is a source reference, not the identity of a newly qualified release package. The final crash/Plex integration and publication build must receive their own evidence.

The updated USB status below was checked against native source `2620a49b72ab9cd0558b1c6f1ff76b6e6e300112`. This identifies implementation, not a qualified release package; the historical results above retain their original source and executable identities.

Classic and Modern share the source/profile model and a saved interface-mode setting. M3U, Xtream, Stalker, VPortal and Plex catalog paths, Local and Server library adapters, categories, portable Favorites and native remote settings are present. The media-attachment setting is provider-scoped and uses runtime, context and revision checks. Favorites retain source identity; a receiving player still needs a matching configured source and local access.

Local folder discovery reads source files rather than importing their media bytes. Verified drive identity can assist rebinding, but does not mount a drive or grant access. Server library remains network-dependent. Torrent uses an optional local companion and a bounded cache; its capability response controls availability. Catalog and stream manifests are separate from remote-control and indexer endpoints.

These observations are source findings. They are not a claim of complete Classic parity, of a final packaged companion, or of successful playback on a particular television.

## Known issues at release, with provenance

- **Classic and Modern are implemented, with qualification still required.** The current candidate has both presentations and a writable `interfaceMode` setting. Earlier Mac screenshots demonstrate their appearance at their own source/binary identity; they do not prove all actions, saved-state behavior or physical-LG compatibility in the final package. Reported selection/persistence failure on an older installed LG build has not yet been closed by a successful repeat on this candidate.
- **Protected Save remains unverified on the receiving LG.** The installed `1c500acb` diagnostic candidate launched, but its fresh-boot diagnostic reports a KeyManager key-generation rejection with service code `-1000` (mapped locally to `capability`, not proof of a missing permission). A writable runtime directory and completed storage-helper connection do not repair this failure. The underlying cause and successful Save retest remain open; pairing approval and durable Save are separate outcomes.
- **Global settings Export/Import is pending.** The supplied transfer contract is a proposal. Its Classic codec and native declaration/fixture checks do not implement or exercise a native importer, transport, persistence transaction or user interface.
- **An attached-media Favorite can be pinned as one kiosk item.** The pin is bound to its exact M3U parent profile and attachment; replay revalidates that binding and the parent authorization. Mixed attached-media kiosk queues are not supported. This source behavior does not establish physical-LG acceptance.
- **Expanded USB folder selection and restoration are present in the reviewed source.** The nested picker and folder-kiosk restore logic validate saved folder and storage bindings. The earlier separate packet's 49 written tests were not compiled or run for that packet; that historical statement is not a result for the current revision. This source check supplies no final-package LG USB access, disconnected-network playback, reattachment or cold-start result. The application must verify its own folder access; a shell-visible mount is insufficient.
- **Final qualification remains open.** Source and partial host checks do not close the normal-Mac candidate, full regression, ARM package, source-closure or physical-LG acceptance requirements. The source must be frozen again after outstanding fixes before results can be attached to a release.
