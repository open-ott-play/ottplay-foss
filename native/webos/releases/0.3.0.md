# OTTPlay Native 0.3.0 — sources, local media and remote control

This version extends the experimental native LG webOS player with the source, interface and remote-control features described below. Hardware validation limits are listed separately.

OTTPlay Native brings television channels and personal media into the native LG application. M3U, Xtream, Stalker, VPortal, Plex and Local sources have provider profiles, categories and a shared Favorites list. Matching source configuration is still required on each player; importing Favorites does not transfer credentials or local files.

## In this version

- **Classic and Modern.** Choose the text-first Classic presentation or the card-based Modern presentation in **Settings → Interface mode**. The choice uses the same saved setting as remote configuration; it does not create separate profiles or Favorites. The implemented interface does not establish complete visual parity or a physical-TV pass.
- **M3U and VPortal together.** A live-playlist profile can retain a private media attachment, resolved when a matching Favorite needs it. A media-only profile can use its portal directly.
- **Local media without importing videos.** Select a source readable by the application. The local catalog can publish admitted videos while discovery continues. A drive being mounted does not establish that the native app can read it. Reconnection to a saved folder requires verified drive identity and access; otherwise select the source again.
- **Optional Torrent and catalog sources.** The packaged local companion supplies capability-dependent Torrent playback with a bounded piece cache. Stremio sources supply configured catalogs and playback choices. Neither is a permanent offline-download library.
- **Native remote control.** Save a command-server address, complete pairing and use the installed player's advertised commands and settings. Saving an address alone does not establish a connection.

## Current limits

Global settings Export/Import remains separate from provider profiles and Favorites transfer; a proposed transfer contract is not proof of an installed importer. An attached-media Favorite can be pinned as one kiosk item bound to its exact M3U parent profile and attachment. Mixed attached-media kiosk queues are not supported. Track menus depend on the active source and decoder; this note does not promise separate HLS audio-rendition switching or a native Picture-in-Picture menu.

The native source includes the nested USB folder picker and folder-kiosk restore logic that validates saved folder and storage bindings. Access to a particular LG drive still depends on the installed build and television. Follow only the controls your installed build offers.

Local playback is offline only when the files are on attached storage and readable by the player; Server library playback still needs its server and network. File extensions do not guarantee that a television can decode the contents. Full Classic behavior and visual parity, physical-LG playback and offline acceptance have not been established for this version. End-of-stream handling for clips lasting one second or less remains unresolved.

## Installing

Before publication, the release workflow must verify the IPK, checksums, build evidence and matching source archives against the selected source revision. These artifact checks do not establish hardware playback or an independent rebuild.

After publication, download the OTTPlay Native IPK and `ottplay-native-webos-0.3.0.sha256` from the same release into one folder. In that folder, verify the downloaded package before installing it:

```sh
shasum -a 256 -c ottplay-native-webos-0.3.0.sha256
```

The command must report `OK` for the IPK. Do not install a package whose verification fails. Follow the [native webOS installation guide](https://github.com/open-ott-play/ottplay-foss/blob/main/native/webos/README.md#install-through-lg-developer-mode) and [update guide](https://github.com/open-ott-play/ottplay-foss/blob/main/docs/native-webos-delivery.md) for Developer Mode or an existing Homebrew Channel. This is a separate native application; updating the hosted player does not update it.
