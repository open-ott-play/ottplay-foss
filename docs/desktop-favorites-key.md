# Desktop Favorites key

On PC and PC2, **F** toggles Favorites for the focused TV channel/video, or the
currently playing item when no list is open. It uses the active provider's
existing Favorites list or media journal. Reordering a list does not change an
item's identity. For Local/Plex/VPortal videos, the existing source/path/provider
identity and persistence rules apply; access URLs are not used as favorite IDs.

Fast forward is **PageDown**; rewind remains **PageUp**. **R** remains random,
and Alt/Ctrl+Left/Right remain seek. Ctrl/Cmd+F keeps browser Find. Typing,
contenteditable fields, modal/PIN dialogs, kiosk mode and held-key repeats do
not toggle Favorites.
