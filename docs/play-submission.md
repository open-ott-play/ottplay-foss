# Android application moved

Android APK/AAB creation, signing and publication now belong to [open-ott-play/ottplay-android](https://github.com/open-ott-play/ottplay-android). That repository is currently a **private preview**; access is required and there is no public Android download promised here.

`ottplay-foss` continues to build the web/server player, Tauri desktop applications and Capacitor iOS application. It no longer has Android Gradle, npm packaging commands or APK/AAB release jobs.

The former Full/Play wrapper documentation is retained only as [historical reference](legacy-android/play-submission.md). It does not apply to the new native application.
